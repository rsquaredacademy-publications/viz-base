Data Visualization with R — Base Graphics · last updated 17 October 2026

This notice covers viz-base.rsquaredacademy.com, the online edition of Data Visualization with R: Base Graphics. The book is free to read and requires no account, no login and no payment.

What this site collects

The book itself collects nothing. There is no comment system, no newsletter signup, no user account and no email field anywhere on the site, so nothing you do here identifies you to us.

The one exception is website analytics, described below.

Analytics

We use Google Analytics 4 to understand how people use this site (pages visited, referring sites, device type and approximate location) so we can improve our free learning material. Google Analytics uses cookies and a pseudonymous identifier; we don't use it for advertising and we never send Google names or email addresses. Visitors in the European Economic Area, the United Kingdom and Switzerland are asked for consent first, and if they decline, no analytics cookies are stored.

Anyone can switch analytics off at any time: Turn off analytics. The choice is remembered for all rsquaredacademy.com sites.

The code that runs in your browser

The interactive playground at the end of Chapters 2 to 4 runs R in your browser through WebAssembly. It executes entirely on your machine: your keystrokes and the data you type stay in your browser and are never sent anywhere. No package downloads are needed, because the book's plotting code uses nothing outside base R.

Apart from the Google Analytics tag (loaded from www.googletagmanager.com), all site fonts, stylesheets and scripts are served from this domain.

The hosting provider

The site is published via GitHub Pages. GitHub serves the files and, like any web server, necessarily sees the IP address and user agent of each request in order to respond. GitHub's handling of that data is covered by the GitHub Privacy Statement.

Your rights

Under the GDPR and comparable regimes you have the right to access, correct, delete or restrict processing of personal data relating to you, and to object to processing based on legitimate interests. Because this site collects no personal data beyond the optional analytics described above, and provides no way to identify an individual visitor, we cannot retrieve data for a named person. Analytics-level rights are best exercised directly with Google through your Google Account's data and privacy controls.
